# Site Física β 0.2

Site de estudo de física, da mecânica clássica até Navier–Stokes, com simulações interativas.

**Como abrir:** baixe o repositório (botão verde *Code* → *Download ZIP*), descompacte e dê dois cliques em `index.html`. Funciona offline.

O andamento está em [PROGRESSO.md](PROGRESSO.md).
