# Site Física β 2.2

Site de estudo de física do Lucas, da mecânica clássica até Navier–Stokes, com simulações interativas, mais Cálculo e Experimentos.

**Como abrir:** baixe o repositório (botão verde *Code* → *Download ZIP*), descompacte e dê dois cliques em `index.html`. Funciona offline.

O andamento e o histórico de versões estão em [PROGRESSO.md](PROGRESSO.md).
